# 🎰 Telegram Казино для Лудиков

Шуточный бот-казино для групповых чатов. Никаких реальных денег — только очки, абсурдные ставки и разбитые надежды.

## Что умеет

Кидаешь 🎰 в чат — бот считает результат, списывает ставку, начисляет выигрыш (или нет). Всё как в настоящем казино, только вместо денег — очки, а вместо депозита — жопа друга.

## Команды

| Команда                | Что делает                                           |
| ---------------------- | ---------------------------------------------------- |
| `/dep`                 | Регистрация. Получаешь 10 фриспинов на старте        |
| `/balance`             | Посмотреть баланс, статистику и количество джекпотов |
| `/top`                 | Топ-10 лудиков в чате                                |
| `/dodep <что ставишь>` | Додепнуть. Пример: `/dodep рот Васи` → +5 очков      |
| `/rules`               | Правила и таблица выигрышей                          |
| `/help`                | То же что /rules, для тех кто не догадался           |

## Выигрыши

**Три в ряд (джекпот):**
7️⃣7️⃣7️⃣ → +50 · BAR BAR BAR → +25 · 🍇🍇🍇 → +15 · 🍋🍋🍋 → +10

**Всё остальное:** 0. Казино благодарит за донат.

## Запуск

```bash
cp .env.example .env
# вписать BOT_TOKEN
npm install
npm start
```

## Стек

Node.js · grammY · SQLite · pm2
