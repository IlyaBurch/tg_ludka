# Telegram Casino Bot

Шуточный бот-казино для группового чата в Telegram. Никаких реальных денег — только очки и абсурдные ставки.

## Стек

- Runtime: Node.js
- Framework: grammY
- БД: SQLite через better-sqlite3
- Конфиг: dotenv, токен в `.env` (`BOT_TOKEN`)

## Механика слотов

Telegram dice emoji 🎰 возвращает `dice.value` от 1 до 64. Декодирование `(value - 1)` в base-4:

```js
const SYMBOLS = ["BAR", "🍇", "🍋", "7️⃣"];

function decodeSlots(value) {
	const v = value - 1;
	return {
		left: SYMBOLS[v % 4],
		center: SYMBOLS[Math.floor(v / 4) % 4],
		right: SYMBOLS[Math.floor(v / 16) % 4],
	};
}
```

### Таблица выигрышей

#### Три в ряд (джекпот)

| Комбинация  | Очки |
| ----------- | ---- |
| 7️⃣ 7️⃣ 7️⃣    | +50  |
| BAR BAR BAR | +25  |
| 🍇 🍇 🍇    | +15  |
| 🍋 🍋 🍋    | +10  |

#### Два совпадения (любые два из трёх)

| Комбинация | Очки |
| ---------- | ---- |
| 7️⃣ 7️⃣ ✖️   | +5   |
| BAR BAR ✖️ | +3   |
| 🍇 🍇 ✖️   | +2   |
| 🍋 🍋 ✖️   | +2   |

Всё остальное → 0, спин потрачен. Каждый прокрут стоит 1 очко (сначала из `free_spins`, потом из `points`).

## Команды

### `/dep`

Регистрирует игрока в текущем чате. Если уже зарегистрирован — шутит. Выдаёт стартовые 10 фри-спинов.

> «Добро пожаловать в казино, лудик! Тебе выдано 10 бесплатных прокрутов. Удачи, она тебе понадобится 🫡»

### `/balance`

Показывает: очки, фри-спины, всего выиграно/проиграно, количество джекпотов.

### `/top`

Топ-10 игроков по очкам в текущем чате. Эмодзи медалей для топ-3.

### `/dodep <текст>`

Игрок «додепает» — описывает что ставит. Пример: `/dodep рот Андрея`

> «Принято! Ты поставил рот Андрея. Тебе начислено 5 очков. Крути, лудик 🎰»

Начисляет 5 очков. Сохраняет запись в таблицу `deposits`.

### `/rules`

Отправляет правила:

```
🎰 ПРАВИЛА КАЗИНО 🎰
1 прокрут = 1 очко ставки

━━━ Три в ряд (джекпот) ━━━
7️⃣ 7️⃣ 7️⃣  →  +50
🎰 🎰 🎰  →  +25
BAR BAR BAR  →  +20
🍇 🍇 🍇  →  +15
🍋 🍋 🍋  →  +10

━━━ Два совпадения ━━━
7️⃣ 7️⃣ ✖️  →  +5
🎰 🎰 ✖️  →  +3
BAR BAR ✖️  →  +3
🍇🍇 / 🍋🍋  →  +2

━━━ Всё остальное ━━━
нет совпадений  →  0

📊 Каждый день — 5 бесплатных прокрутов
💰 Закончились очки? Додепай /dodep
📉 Шанс 777: ~0.8%

Удачи, лудики 🫡
```

## Обработка 🎰 в чате

Слушать `message:dice` где `dice.emoji === '🎰'`.

1. **Не зарегистрирован** → удалить сообщение, ответить «Сначала зарегистрируйся через /start, халявщик»
2. **Нет очков** (`free_spins === 0 && points === 0`) → удалить сообщение через `ctx.deleteMessage()`, ответить: «У тебя 0 на счету, лудик. Сначала додепни через /dodep 🫠»
3. Списать 1 спин (сначала из `free_spins`, потом из `points`)
4. **Подождать 3 секунды** (промис с setTimeout) — чтобы анимация доиграла
5. Декодировать результат
6. Начислить выигрыш
7. Ответить reply на сообщение:
   - **Джекпот (три в ряд):** «🎉 ОКУП! [символы] — +{очки} очков! Баланс: {баланс}»
   - **Два совпадения:** «Неплохо, [символы] — +{очки}. Баланс: {баланс}»
   - **Проигрыш:** рандомная фраза из пула (6-8 вариантов):
     - «Лол, слил. Баланс: {баланс}»
     - «В трубу. Баланс: {баланс}»
     - «Мимо кассы, лудик. Баланс: {баланс}»
     - «Даже бабушка крутит лучше. Баланс: {баланс}»
     - «Ты точно не мог просто деньги на ветер? Баланс: {баланс}»
     - «Казино благодарит за донат. Баланс: {баланс}»
     - «💀 Баланс: {баланс}»

## Ежедневные фри-спины

При каждом взаимодействии игрока проверять `last_daily`. Если дата отличается от сегодня — начислить 3 `free_spins`, обновить `last_daily`. Тихо, без отдельного сообщения, но в `/balance` показывать.

## Стиль

Тон — **дерзкий, панибратский, но добрый**. Бот обращается к игрокам «лудик»,«лудоман» «казиноголик» и т.п. Эмодзи: 🫡 🎰 💀 🫠 🤡 — уместно, но не перебарщивать.

## Технические требования

- Бот работает ТОЛЬКО в группах (`chat.type !== 'private'` для слотов)
- Все ответы — reply на сообщение игрока
- `parse_mode: 'HTML'` везде
- Если не удалось удалить сообщение (нет прав админа) — просто ответить текстом
- Логирование ошибок: `console.error`
- Graceful shutdown: `process.once('SIGINT')` / `process.once('SIGTERM')`
